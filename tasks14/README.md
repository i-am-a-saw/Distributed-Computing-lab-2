# Лабораторная работа №2 — OpenMP (задачи 1 и 4)

Минимальный архив **только с исходным кодом**, предназначенный для изучения и проверки запуска. Включены четыре исходных файла C++, `Makefile` и эта инструкция. Версии программ с тестами, автоматизированными замерами, графиками и отчётом находятся в полном проекте; в этот облегчённый комплект они не входят.

## Сборка в Ubuntu / WSL

```bash
sudo apt update
sudo apt install -y build-essential
cd lab2_openmp
make
```

Появится исполняемый файл `build/lab2`. Компилятор должен поддерживать C++17 и OpenMP (`g++ -fopenmp`).

## Примеры запуска

```bash
./build/lab2 --help
./build/lab2 pi --mode seq --n 1000000 --seed 1
./build/lab2 pi --mode par --n 1000000 --threads 4 --seed 1
./build/lab2 call --gen mcg59 --mode seq --n 1000000 --seed 37
./build/lab2 call --gen mcg59 --mode par --n 1000000 --threads 4 --seed 37
./build/lab2 call --gen sobol --mode par --n 1000000 --threads 4 --s0 100 --k 100 --r 0.05 --sigma 0.2 --t 1
```

`pi` оценивает число π методом Монте-Карло. `call` оценивает цену европейского колл-опциона и сравнивает её с аналитической формулой Блэка–Шоулса. Аргумент `--mode par` выбирает OpenMP-вычисления, `--threads` задаёт число потоков.

## Файлы

- `src/main.cpp` — параметры командной строки, запуск режимов, вывод результатов.
- `src/lab.cpp` — расчёт π, стоимости опциона, эталона Блэка–Шоулса, таймеры и параллельные циклы.
- `src/lab.hpp` — интерфейсы и объявления.
- `src/random.cpp` — генераторы MCG59 и Соболя, обратная нормальная CDF.
- `Makefile` — сборка `build/lab2`.
- `README.md` — краткая инструкция.

Этот комплект позволяет **скомпилировать и выполнить обе задачи**, но не содержит автоматических тестов и скриптов построения графиков. Поэтому команда `make test` здесь не предусмотрена.
