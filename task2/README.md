# Лабораторная работа №2: Параллельный алгоритм Препараты-Хонга построения выпуклой оболочки (OpenMP)

Данный проект содержит полную реализацию параллельного алгоритма Препараты-Хонга для построения выпуклой оболочки множества точек на плоскости с использованием технологии многопоточного параллелизма **OpenMP**. В проект также включены эталонный последовательный алгоритм Эндрю (Monotone Chain), последовательный алгоритм Препараты-Хонга, модули бенчмаркинга, скрипты визуализации и подробный научный отчет.

Исходный код `preparata_hong.cpp` содержит **подробные комментарии на русском языке к каждой строке**, что позволяет детально разобрать логику работы алгоритма и защитить лабораторную работу.

---

## 1. Формулировка задачи и форматы данных

### Формат входных данных:
* В первой строке натуральное число $N$ (до 100 миллионов) — количество точек.
* Далее $N$ строк, в каждой из которых пара вещественных чисел $x_i, y_i$ через пробел.

### Формат выходных данных:
* В первой строке натуральное число $K$ — количество вершин выпуклой оболочки.
* Далее $K$ строк, в каждой из которых пара чисел — координаты вершин.
* Вершины следуют в **порядке обхода против часовой стрелки** (CCW), начиная с любой крайней вершины.

---

## 2. Структура проекта

* `preparata_hong.cpp` — исходный код на C++17 (все 3 алгоритма: Эндрю, последовательный Препарата-Хонг, параллельный OpenMP Препарата-Хонг, бенчмарк и генератор данных). Каждая строка подробно прокомментирована на русском языке.
* `visualize.py` — Python-скрипт для визуализации выпуклой оболочки (демонстрация корректности) и построения графиков времени, ускорения и эффективности.
* `test_runner.py` — автоматический тестовый раннер (23 теста: краевые случаи, вырожденные прямые, окружности, случайные наборы).
* `Makefile` — сценарий автоматизации сборки и запуска под Linux и macOS.
* `benchmark_results.csv` — экспериментальные замеры времени работы и ускорения для $N$ от 10 000 до 10 000 000 точек.
* `convex_hull_demo.png` — визуализация корректности работы алгоритма с обходом против часовой стрелки (CCW).
* `plot_time_vs_threads.png` — график времени выполнения $T(p)$ от числа потоков.
* `plot_speedup.png` — график ускорения $S(p) = T(1) / T(p)$.
* `plot_efficiency.png` — график эффективности $E(p) = S(p) / p$.
* `plot_algorithms_comparison.png` — сравнительный график быстродействия трех алгоритмов от $N$.
* `plot_distributions.png` — исследование зависимости от типа входных данных (квадрат, круг, Гаусс).
* `input_sample.txt` / `output_sample.txt` — примеры входных и выходных данных.
* `REPORT.md` — подробный академический отчет о проведенной работе с таблицами, графиками и выводами.

## 3. Требования к окружению

* **Компилятор C++**: `g++` (версия 9+ на Linux) или `clang++` с библиотекой `libomp` (на macOS).
* **OpenMP**: поддержка OpenMP 3.0+.
* **Python 3**: для запуска визуализатора и тестов (`matplotlib`, `numpy`).

## 4. Инструкция по сборке и запуску

### 4.1 Сборка проекта

#### Вариант А: С использованием `make` (рекомендуется)
```bash
make
```

#### Вариант Б: Ручная компиляция на Linux (GCC)
```bash
g++ -O3 -std=c++17 -fopenmp preparata_hong.cpp -o preparata_hong
```

#### Вариант В: Ручная компиляция на macOS (Clang + Homebrew libomp)
```bash
clang++ -O3 -std=c++17 -Xpreprocessor -fopenmp \
    -I$(brew --prefix libomp)/include \
    -L$(brew --prefix libomp)/lib -lomp \
    preparata_hong.cpp -o preparata_hong
```

---

### 4.2 Запуск программы

#### Решение задачи на входных данных:
Программа считывает входные данные из стандартного потока ввода `stdin` и выводит результат в `stdout`. Количество потоков можно передать первым аргументом командной строки (по умолчанию используются все доступные аппаратные потоки):

```bash
# Запуск со всеми доступными потоками CPU
./preparata_hong < input_sample.txt

# Запуск с явным указанием 4 потоков OpenMP
./preparata_hong 4 < input_sample.txt

# Сохранение результата в файл
./preparata_hong 8 < input_sample.txt > output.txt
```

#### Запуск встроенных бенчмарков:
Программа автоматически протестирует все три алгоритма на различных объемах данных (от 10 000 до 10 000 000 точек) и распределениях (квадрат, круг, Гаусс) и сохранит результаты в CSV:
```bash
./preparata_hong --benchmark benchmark_results.csv
# или через make:
make benchmark
```

#### Генератор случайных тестовых точек:
```bash
# Сгенерировать 100000 точек в квадрате и сохранить в input.txt
./preparata_hong --generate 100000 square > input.txt
```

## 5. Выводы по исследованию быстродействия

Подробный анализ, графики и таблицы приведены в файле `REPORT.md`. Основные тезисы:
1. **Параллельный алгоритм Препараты-Хонга (OpenMP)** показывает значительное ускорение (до $5.93\times$ на 10 потоках для 1 млн точек и до $9.02\times$ на 8 потоках при нормальном распределении) по сравнению с последовательным алгоритмом за счет эффективной независимой обработки блоков точек потоками и быстрого логарифмического слияния по дереву редукции.
2. **Алгоритм Эндрю (Monotone Chain)** эффективен в последовательном режиме благодаря простому стековому проходу без рекурсивных вызовов, однако не масштабируется на многоядерные архитектуры.
3. **Зависимость от входных данных**: для распределений с малым числом вершин на оболочке ($K \ll N$, например, квадрат или Гаусс) алгоритм Препараты-Хонга работает быстрее всего, так как операция слияния оболочек выполняется за $O(K)$, что для 10 млн точек занимает доли миллисекунды. При распределении на круге ($K \sim N^{1/3}$) время слияния незначительно возрастает, но параллелизм сохраняет высокую эффективность.
